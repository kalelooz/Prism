Theme copied

Theme copied to your clipboard.

  1. In your current Codex window, open Settings → Appearance. The button below opens that same window.
  2. Select Dark at the top, then click Import under Dark theme.
  3. Click the theme text box and press Ctrl+V. Use Copy again below if you copied something else.
  4. Click Import theme to finish.

This copies colors and fonts. Your background is managed separately in Prism → Backgrounds. Use Save theme to keep the colors and fonts in your library.

Theme backups

Restore copies the saved theme. Finish by importing it in Codex. Prism never reads your conversations or changes Codex files.

Connection details

Quit ChatGPT completely

Windows lists this Codex app as ChatGPT.exe. Closing its windows can leave it running.

  1. Save your work and let running tasks finish.
  2. Near the Windows clock, open the hidden icons arrow. Right-click the ChatGPT / Codex icon and choose Quit. Wait about 15 seconds.
  3. If Prism still waits, open Task Manager → Details. Find ChatGPT.exe with a matching PID below, select it, then choose End task. Start with the main process; repeat for remaining listed entries if needed.

End task interrupts running work and can lose unsaved changes. Only end the listed ChatGPT.exe processes; another ChatGPT app may use the same name.

Keep Prism running, then use Open Codex.
